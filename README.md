## Как обновить страницу

1. Открой сайт с `#edit` в конце адреса: https://hanryy23.github.io/teplo-zemly-annapurna-circuit/#edit
2. Правь тексты и фото прямо на странице, затем нажми «Скачать HTML».
3. Замени `index.html` в этом репозитории скачанным файлом (Add file → Upload files).
